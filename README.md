Soy desarrollador full stack y fundador de **Agilize Soluciones**. Ayudo a empresas y emprendedores a digitalizar sus negocios con software a medida: desde sistemas de gestión empresarial (ERP) hasta tiendas online y páginas web que convierten visitantes en clientes.

## 🏢 Productos & Servicios

### 🔥 Agilize Gestión — ERP Empresarial

<p align="center">
  <a href="https://github.com/Jorge-Loyo/AGILIZE-GESTION">
    <img src="https://img.shields.io/badge/AGILIZE_GESTIÓN-ERP_Empresarial-00C9FF?style=for-the-badge&logo=python&logoColor=white" />
  </a>
</p>

> Sistema de gestión empresarial completo para PyMEs que necesitan orden y control en su negocio.

| Característica | Detalle |
|---|---|
| 📦 Inventario | Control de stock en tiempo real |
| 💰 Ventas | Registro y seguimiento de ventas |
| 👥 Clientes | Gestión de cartera de clientes |
| 📊 Reportes | Dashboards y análisis de datos |
| 🔐 Multi-usuario | Roles y permisos personalizados |

**Stack:** Python · FastAPI · PostgreSQL · React

### 🛒 Casa Dulce — E-commerce de Repostería

<p align="center">
  <a href="https://github.com/Jorge-Loyo/tienda-reposteria">
    <img src="https://img.shields.io/badge/CASA_DULCE-E--commerce-92FE9D?style=for-the-badge&logo=nextdotjs&logoColor=black" />
  </a>
</p>

> Tienda online completa con catálogo, carrito de compras, pasarela de pagos y panel de administración.

| Característica | Detalle |
|---|---|
| 🛍️ Catálogo | Productos con categorías y filtros |
| 🛒 Carrito | Experiencia de compra fluida |
| 💳 Pagos | Integración con pasarelas de pago |
| 📱 Responsive | Diseño adaptable a cualquier dispositivo |
| ⚡ Performance | Optimizado para velocidad y SEO |

**Stack:** Next.js · Prisma · PostgreSQL · Tailwind CSS
